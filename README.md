# pixel-startup — JavabFast (جواب‌سریع)

AI assistant that auto-answers Instagram DMs for small Iranian shops.

- Each team writes `teams/<team>/report.md`
- Build live dashboard: `python build_dashboard.py`
- Set office URL via env: `PIXEL_OFFICE_URL=http://127.0.0.1:3100/ python build_dashboard.py`
